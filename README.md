# MusterLog

A shop-counter CRM. People and organizations sit on a Sales board and an Onboarding board. Each workspace only sees its own book.

Mail and the agent door are drawn in and locked behind the Pro plan. Nothing sends, and no agent API is live.

You may clone this and run it for your own book. The [license](LICENSE) reserves selling a hosted book to other people.

See [deploy/README.md](deploy/README.md) for a DigitalOcean droplet and for local development.
